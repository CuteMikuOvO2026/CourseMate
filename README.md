# CourseMate · 课程资料学习助手

把一门课的 PPT、讲义、作业说明和个人笔记，变成**可追溯、可练习、可复习**的个人知识库。

上传资料后，你可以围绕课程材料提问，每个回答都带文件名、页码/章节和原文片段，点一下就能回到原文核对；资料里没有依据时，它会明确说"不知道"，而不是编一个答案。复习时可以从指定资料生成小测和记忆卡，作业说明里的截止日期也会被帮你找出来。

---

## 它适合谁用

适合**正在上课、需要反复翻资料**的学生：复习时要快速定位"老师在第几讲讲过这个"、交作业前要核对要求和截止时间、考前想针对薄弱点自测。

它不是通用聊天机器人，也不替你做作业——回答只基于你上传的资料。

| 场景 | 你可以这样问 / 这样做 | 你会得到 |
|---|---|---|
| 课后回顾 | "第 4 讲怎么解释死锁？" | 简洁解释 + 可点回对应 PPT 页 |
| 作业核对 | "本次实验报告要交什么、何时截止？" | 要求清单与日期，附原文出处 |
| 考前复习 | "根据第 1–6 讲出 10 道选择题" | 题目、答案、解析都对应材料 |
| 错题复盘 | 在练习页重做做错的题 | 错题关联解析与来源 |
| 信息不足 | "老师上课会不会点名？" | 明确说明资料中没有依据 |

## 能做什么

**1. 课程与资料管理**
按课程组织一切：创建课程、上传资料，课程之间数据完全隔离。支持 PDF、PPTX、DOCX、Markdown、TXT（单文件不超过 50 MB）。上传后自动解析，PDF 保留页码、PPT 保留幻灯片号、Word/Markdown 按章节定位；解析失败会告诉你原因，可以一键重新解析。已解析的资料可以按页/章节预览提取出的原文。

**2. 带出处的课程问答**
- 回答只来自当前课程的资料，附文件名、页码/幻灯片、章节和原文片段，可打开原文件核对；
- 资料不足时**明确拒答**，不用常识补全；
- 支持这些问法："第 13 页讲了什么"、"第 13 张幻灯片"、"这份资料主要讲了什么"；
- 英文提问也能命中中文资料（语义检索），但跨语言回答需要模型模式；
- **模型回答**像聊天一样逐段流出（流式输出）；也可以切换成**离线原文摘录**，完全不调用外部模型。

**3. 小测**
选择资料范围、题量和题型，自动生成题目；提交后自动判分，错题附参考答案、解析和原文出处，历史成绩随时回看。

**4. 复习卡**
按选定资料生成问答卡，也可以手动创建；点击卡片翻面复习，标记"已掌握 / 不熟"，记录复习次数，每张卡都保留来源原文。

**5. 资料待办**
自动扫描作业说明里的"截止 / 提交 / deadline"等表述，提取候选截止日期；你确认（可修改时间）后才生成待办，支持逾期提醒、完成勾选、编辑和删除。

## 快速开始

需要一台自己的电脑（Windows），数据只存在本机。

**第一次使用（各做一次）：**

1. 准备后端环境——在项目目录打开 PowerShell 运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
   ```
   （需要 Python 3.12 及以上）

2. 构建网页界面：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\build-web.ps1
   ```
   （需要 Node 20 及以上；脚本会自动寻找本机 Node/pnpm）

3. （可选）生成一份演示课程，含 7 份示例资料：
   ```bash
   cd backend
   ..\.venv\Scripts\python.exe scripts\seed_demo.py
   cd ..
   ```

**以后每次使用：**

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run.ps1
```

然后浏览器打开 **http://127.0.0.1:8000** 即可。

- 想直接看看效果：用演示账号登录 **`demo` / `coursemate123`**；
- 想用自己的资料：点「注册」，用户名 + 至少 8 位密码，然后创建你的第一门课程。

## 使用指南

### 第一次进来：认识界面

登录后是工作台：**左侧是导航栏**（品牌、当前课程、五个功能入口、底部你的账户），右侧是内容区。

课程内的五个入口：

| 入口 | 用来做什么 |
|---|---|
| 资料 | 上传、查看、预览、删除课程文件 |
| 问答 | 围绕资料提问，查看带引用的回答 |
| 练习 | 生成小测、提交作答、回看成绩 |
| 复习卡 | 生成/手动创建卡片，翻面复习 |
| 待办 | 扫描截止日期、管理作业提醒 |

### 第一步：上传资料

进入课程 → 「资料」页 → 拖拽或选择文件上传。状态会自动从「等待解析」变成「已解析」。「已解析」后即可用于问答、练习和卡片生成。上传前可以删除，上传后也能删。

### 第二步：提问

「问答」页输入问题，例如：

- "死锁的四个必要条件是什么？"
- "第 13 页讲了什么？"（直接定位到指定页）
- "这份资料主要讲了什么？"（整份总结）
- "实验报告要交哪些内容？"

回答下方会显示**引用来源**：文件名、页码/章节和原文片段，点「打开原文件」可下载核对。每个回答还标注了置信度、生成模式（模型生成 / 原文摘录）和实际使用的模型。

顶栏可以切换两种回答模式：

- **模型回答**（推荐，需配置模型）：用大模型组织语言，回答更完整，逐段流式输出；
- **离线原文摘录**：不调用任何外部模型，直接从资料中摘录相关句子，完全离线可用。

### 第三步：练习与复习

- **练习**：选资料 → 选题量和题型 → 生成小测 → 作答提交 → 看分数与错题解析；
- **复习卡**：选资料生成卡片，或手动添加；点卡片翻面，用「已掌握 / 不熟」记录状态；
- **待办**：点「扫描候选截止日期」从作业说明中找日期，确认后生成待办；也可以手动添加。

## 常见问题

**问：为什么有时候回答"资料不足，暂不能回答"？**
这是刻意设计。系统只在你的资料里找依据，找不到就明说，而不是用常识编一个看起来合理的答案。你可以换个问法，或先上传相关章节的资料。

**问：扫描版 PDF 上传后失败？**
目前不支持 OCR，无法从扫描图片中提取文字，会明确提示失败。请尽量上传文字版 PDF；如果只有扫描件，其中的内容暂时无法用于问答。

**问：图片很多的 PPT 为什么只能问到标题？**
这类幻灯片的正文在图片里，目前只能提取到标题和少量文本，暂时无法解释图内容。

**问：模型回答和离线回答有什么区别？**
模型回答由大模型基于检索到的原文组织语言，能总结、能跨语言；离线回答直接从原文摘录句子，不总结、不改写。两种模式都带同样的引用校验，模型调用失败时会自动降级为离线回答并标注。

**问：我的资料和记录存在哪？安全吗？**
全部只存在你自己电脑上（本地数据库 + 本地文件存储），不上传到任何第三方；模型 API 密钥也只写在你自己的配置里。账户之间、课程之间的数据完全隔离。

**问：忘记密码怎么办？**
目前没有自助找回功能，需要用新用户名重新注册（旧账户的资料无法迁移，所以请记好密码）。

**问：可以多人一起用吗？**
当前版本面向个人使用：一个浏览器会话一个账户，资料按课程隔离。团队共享暂不支持。

## 已知限制

- 扫描版 PDF 不支持 OCR，会明确失败并提示；
- 图片/公式为主的幻灯片只能提取到标题或碎片；
- 离线回答是原文摘录，不总结、不改写；
- 小测与复习卡由规则生成，质量取决于原文；
- 单用户本地使用，暂不支持多人协作。
